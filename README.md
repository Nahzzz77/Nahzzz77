### About

我是张涵，一名 AI 产品经理。

我喜欢把复杂问题拆清楚，再用原型、评测和真实使用反馈验证判断。比起“模型有多强”，我更关心用户能不能看懂、敢不敢使用，以及产品出错时能不能继续完成任务。

### Now

- 研究 AI Agent 的执行边界、交互体验与异常恢复
- 把产品拆解、竞品研究和中文写作方法做成可复用的 Codex Skills
- 持续记录 AI 产品判断、项目复盘与真实使用体验
